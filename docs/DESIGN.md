# 盘镜 MarketLens — 设计语言

盘镜的界面不是「把卡片摆好看」，而是**把看盘这件事按专业终端的逻辑重新排布一遍**。
本文记录设计决策背后的理由，方便后续贡献者保持一致。

---

## 参考对象

| 来源 | 借鉴的东西 | 明确没借鉴的东西 |
|---|---|---|
| **Bloomberg Terminal** | 信息密度、等宽数字、面板式分区、底部状态栏、持续滚动的行情带 | 橙色以外的彩色高饱和、大量快捷键彩蛋 |
| **LSEG Workspace** | 中文 + 大写拉丁的双语微标签、细发丝线、右侧监控列 | 其品牌色与图标 |
| **S&P Global / Capital IQ** | 板块热力图、关键指标网格、财务摘要条形图 | 其配色 |
| **TradingView** | K 线 + 成交量 + 副图的图表结构 | 亮色圆角 UI、社交功能 |

刻意**不**采用的风格：消费级 SaaS 的大圆角卡片、柔和渐变、悬浮阴影、插画式空状态。
盘镜要的是「坐下来看一天盘」的密度，不是「刷一眼资讯」的松弛。

## 布局骨架

```
┌────────────────────────────────────────────────────────────┐
│ 顶栏：品牌 │ 市场状态灯 ×7 │ ⌘K 搜索 │ 配色 │ 主题 │ 时钟      │
├────────────────────────────────────────────────────────────┤
│ 行情跑马灯（连续滚动，左右渐隐遮罩）                          │
├────────┬───────────────────────────────┬───────────────────┤
│ 左轨    │ 中栏：主工作区                 │ 右栏：监控列       │
│ 工作台  │                               │ 自选监控           │
│ 总览    │  视图头                        │ 领涨 / 领跌        │
│ 行情    │  ┌ 面板 ────────────────────┐ │ 财经要闻           │
│ 自选    │  │ 面板标题：中文 · ENGLISH  │ │ 价格提醒           │
│ 榜单    │  │ ───────────────────────  │ │                   │
│ ────   │  │ 面板内容                  │ │                   │
│ 市场    │  └──────────────────────────┘ │                   │
│ ────   │                               │                   │
│ 数据源  │                               │                   │
├────────┴───────────────────────────────┴───────────────────┤
│ 状态栏：连接状态 │ 数据源+延迟 │ 上次刷新 │ 刷新倒计时 │ 免责声明 │
└────────────────────────────────────────────────────────────┘
```

- 顶栏 / 跑马灯 / 工作区 / 状态栏 四行固定，只有工作区滚动。
- 右栏在 < 1240px 隐藏，左轨在 < 880px 隐藏。
- 中栏用 CSS Grid 自适应分栏（`repeat(auto-fit, minmax(320px, 1fr))`），
  所以「涨幅榜 / 跌幅榜」这类并排面板在宽屏并排、窄屏自动堆叠。

## 视觉令牌

全部定义在 `public/styles/tokens.css`。

### 深色（默认，终端感）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#06080c` | 页面底色 |
| `--panel` | `#0c111a` | 面板底 |
| `--panel-2` | `#101722` | 面板头 / 次级区块 |
| `--panel-3` | `#151d2b` | 表头 / 浮层 |
| `--line` | `#1a2331` | 发丝线 |
| `--fg` | `#c9d5e6` | 主文字 |
| `--fg-2` | `#8496ae` | 次要文字 |
| `--fg-3` | `#56657c` | 微标签 |
| `--fg-4` | `#3b4859` | 极弱提示 |
| `--amber` | `#ffb020` | 强调色（Bloomberg 橙） |

### 浅色（纸白终端）

底色 `#eef1f5`、面板纯白、文字 `#16202e`，强调色压暗到 `#b8790a` 保证对比度。

### 涨跌配色

用 `html[data-direction]` 切换，默认 `cn`（红涨绿跌）：

```css
html[data-direction="cn"]   { --up: #ff4d4f; --down: #0fc17e; }
html[data-direction="intl"] { --up: #0fc17e; --down: #ff4d4f; }
```

所有涨跌相关的组件只引用 `var(--up)` / `var(--down)`，所以切换配色不需要改任何组件代码。

## 排版

- **数字**：`ui-monospace` + `font-variant-numeric: tabular-nums`。
  表格数字必须等宽，否则一列价格没法上下对齐 —— 这是终端和 App 最明显的区别。
- **正文**：`PingFang SC` / `Microsoft YaHei` 系统字体栈，13px 基准。
- **微标签**：9px、大写、`letter-spacing: 0.14em`。
  面板标题一律「中文 · ENGLISH」双语组合。

---

## 组件约定

| 组件 | 约定 |
|---|---|
| `.panel` | 直角（2px），1px 发丝边框，无阴影 |
| `.panel-hd` | 固定 30px 高，标题 + 英文 + 细分隔线 + 右侧工具区 |
| `.tbl` | 表头 sticky，等宽数字右对齐，代码列用 `--amber` |
| `.chip` | 9px 大写等宽，用作标签与可点击开关（`.chip-btn`） |
| `.mon-block` | 右栏区块，比 `.panel` 更紧凑（26px 头） |
| `.heat-tile` | 用半透明色块叠加表达强度（`.heat-wash`），不用滤镜 |

热力图的颜色强度用「不透明度叠加」而不是 `color-mix()`，
是为了兼容更老的浏览器，同时保证深浅两套主题下都能正确叠加。

---

## 动效

- 只做功能性动效：面板淡入、提示条滑入、跑马灯滚动、数字变化。
- 不做装饰性动效：没有入场动画、没有 hover 缩放（热力图瓦片除外，因为它帮助定位）。
- `prefers-reduced-motion` 下应关闭跑马灯滚动（目前由浏览器默认处理，未强制）。

---

## 数据可视化的克制

- 图表右轴同时给**价格**和**涨跌幅**两行，专业用户看涨跌比看绝对值更常用。
- 最新价有一条虚线横标 + 右侧色块标签。
- 成交量用半透明柱，颜色跟随 K 线方向。
- RSI 副图标出 30 / 70 两条虚线参考位；MACD 副图柱子用涨绿跌红并降低不透明度，避免喧宾夺主。
- 空状态统一用 `—`，不用插画。

---

## 中文本地化

- 界面文案全部中文，术语按国内交易员习惯（成交量、52 周区间、涨跌幅、盘前/盘后）。
- 行情标题保留英文原文（来自 Yahoo），但来源、板块、时间都做了中文化包装。
- 数字用中文习惯的万亿 / 亿 / 万压缩（`fmtCompact`）。
- 时间一律北京时间显示（`Asia/Shanghai`）。
